# NutLens

NutLens adalah situs statis berbasis HTML, CSS, dan JavaScript modules.

## Konvensi class CSS

- Gunakan kebab-case untuk seluruh class kustom, misalnya `navbar-services-toggle`.
- Gunakan awalan nama komponen untuk menjaga selector tetap terkelompok, misalnya `recipe-hero-title`.
- Class dari library eksternal, seperti `material-symbols-outlined` dan `bi-facebook`, tidak diubah.
